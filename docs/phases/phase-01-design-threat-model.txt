 TASKS - THREAT MODEL (P7)
-------------------------------------------------------------------------------

 [ ] [KIRO]    Choose tool: OWASP Threat Dragon
                 Cited in Prates & Pereira Table 8 (6 mentions) so the choice
                 is defensible from the source paper.
 [ ] [KIRO]    Apply STRIDE per data flow
 [ ] [KIRO]    Minimum threats to cover (from the attack plan):
                 [ ] Tampering with listingId to edit another seller's item
                     -> server-side ownership check, ASVS 8.2.2
                 [ ] Two buyers purchase the same unique item
                     -> transactional row lock, ASVS 2.3.4
                 [ ] Upload of an executable disguised as an image
                     -> magic bytes + re-encode + no-exec store, ASVS 5.2.2/5.3.1
                 [ ] Bulk scraping of listings and seller data
                     -> rate limiting / anti-automation, ASVS 2.4.1
                 [ ] Prompt injection via listing title into the LLM
                     -> input sanitisation, output encoding, no secrets in prompt
                 [ ] Injection via the search parameter
                     -> parameterised queries / ORM, ASVS 1.2.4
                 [ ] Privilege escalation to the admin moderation endpoint
                     -> function-level authz, ASVS 8.2.1
                 [ ] Stored XSS via review body
                     -> output sanitisation, ASVS 1.3.1
                 [ ] Token forgery / alg:none
                     -> algorithm allow-list, ASVS 9.1.2
 [ ] [KIRO]    Trace EVERY mitigation to a specific ASVS requirement ID
                 This table becomes the backbone of the report.
