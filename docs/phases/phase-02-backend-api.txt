 GOAL
-------------------------------------------------------------------------------

 Build the Express.js REST API with every security control designed in, each
 one carrying a code comment naming its ASVS requirement ID.

 The ASVS annotations are not decoration: they make the traceability table in
 the report mechanical to produce, and make questions in the oral defence easy
 to answer by pointing at the code.

   Node.js 22 + Express + TypeScript
   PostgreSQL + Prisma ORM     (parameterised queries by default)
   Zod                         (schema validation)
   Argon2id                    (password hashing)
   Helmet                      (security headers)
