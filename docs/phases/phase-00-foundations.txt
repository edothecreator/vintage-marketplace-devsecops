-------------------------------------------------------------------------------
 NOTES / GOTCHAS LEARNED IN THIS PHASE
-------------------------------------------------------------------------------

 1. GitHub Free does NOT allow branch protection OR rulesets on private
    repositories. Both APIs return HTTP 403 "Upgrade to GitHub Pro or make this
    repository public". This forced the visibility decision - see ADR 0004.

 2. Public visibility activates GitHub's own secret-scanning push protection,
    which would BLOCK the Phase 09 V2 demo if it used a Google API key. V2 now
    uses the hardcoded JWT secret pattern instead. Documented in .gitleaks.toml
    and ADR 0004.

 3. CODEOWNERS silently ignores usernames that are not collaborators. The file
    can look like a working control while enforcing nothing. ALWAYS verify with
    the codeowners/errors endpoint.

 4. Required status check contexts must match job NAMES exactly. A rename in
    ci.yml silently detaches the protection rule.

 5. Git Credential Manager hangs when it cannot show a dialog. gh auth setup-git
    routes git credentials through the gh token instead.

 6. pre-commit.exe is not on PATH on this machine. Use: python -m pre_commit
